## Acerca del proyecto

Este repositorio contiene la web de VET lens, un proyecto en desarrollo para facilitar la consulta de información oficial sobre medicamentos veterinarios.

La app se prepara tomando como referencia los datos públicos de CIMA Vet, el registro de medicamentos veterinarios de la Agencia Española de Medicamentos y Productos Sanitarios (AEMPS). La futura consulta podrá incluir datos por especie de destino, presentaciones, condiciones de uso, fichas técnicas, prospectos y otra información disponible en el registro.

## Sobre este sitio

La web está creada con Astro y JavaScript. El despliegue se realiza con Netlify.

```bash
npm install
npm run dev
npm run build
npm run preview
```

Los enlaces de Google Play y App Store están desactivados hasta que la aplicación se publique. La información de `/changelog` y `/roadmap` se añadirá próximamente.
